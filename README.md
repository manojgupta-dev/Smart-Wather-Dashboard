# Weatherly — Smart Weather Dashboard

A modern, responsive weather dashboard built with HTML, CSS, and JavaScript.

Weatherly allows users to search for cities, view current weather conditions, check hourly and 5-day forecasts, use their current location, switch temperature units, and toggle between dark and light themes.

## Features

- 🔍 Search weather by city
- 📍 Detect weather using current location
- 🌡️ Celsius / Fahrenheit toggle
- 🌙 Premium dark mode
- ☀️ Light mode
- 🕐 Current date and time
- 🌤️ Current weather conditions
- 💧 Humidity
- 💨 Wind speed
- 📊 Atmospheric pressure
- 👁️ Visibility
- 🌅 Sunrise and sunset
- ⏱️ Hourly weather forecast
- 📅 5-day weather forecast
- 🌿 Air quality information
- ⚠️ Error handling for invalid cities
- ⏳ Loading state while fetching data
- 📱 Fully responsive design

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Fetch API
- Open-Meteo API
- Geocoding API
- Browser Geolocation API
